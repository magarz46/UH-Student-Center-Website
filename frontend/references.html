Development References

This website was developed with the help of Copilot AI. AI assisted in creating the website outline, including the basic HTML structure and CSS for the grid structure and title bar. AI also contributed to the room booking form, specifically the JavaScript validation logic and CSS styling. Throughout development, AI was also used as an assistant that helped answer questions, debug code, and provide suggestions.

Below are the major prompts used to help create this website.

Prompt 1

This prompt was used to create the initial website outline. It created the basic HTML for all five pages, a navigation bar, and simple CSS styling. Follow up prompts were used to play around with the different color schemes and styles used. The HTML classes it created were very useful since they worked for nearly the entire website.

Prompt 2

This prompt was used to add a section for images on the home page. It created a new class for images and utilized the existing outline-block class to create an elegant looking image card.

Prompt 3

This prompt was used to create the room booking form field aswell as validation checks for the data entered. In hindsight, this prompt was a bit too broad as the output it created was quite complex. I had to refine the room booking form with several follow up prompts and tweak the JavaScript to fit my use case.

Prompt 4

This was one of the follow up prompts for the room booking form validation checks. The initial prompt created over 200 lines of code that diligently checked every data entry. This helped refine the validation check to a much simpler solution that fit my use case.
